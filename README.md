# viju · DS-393 · Список каналов

Прототип ленты каналов на главной (мобильное приложение) и спецификация для разработки iOS и Android.

**Открыть:** страница GitHub Pages этого репозитория. Доступ по паролю, пароль у дизайнера.

Внутри после ввода пароля:

- кликабельный прототип: все 34 канала, переход «Морф», выбор iPhone;
- кнопка «Для разработки»: раскладка и размеры, жесты и пружина, формулы морфа, слои неактивной карточки, запасные варианты данных, видео;
- эталонный код SwiftUI и Jetpack Compose с кнопкой «Скопировать»;
- разметка на макете с живыми значениями.

В этой задаче прорабатываются **неактивные карточки** и переход между каналами. Активная карточка в прототипе — набросок, а не финальный дизайн.

Содержимое зашифровано (AES-GCM, ключ из пароля через PBKDF2). Файлы `p0.bin`–`p2.bin` без пароля не читаются.
